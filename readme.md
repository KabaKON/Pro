      # MON Projet JavaScript

       # Présentation
APK-Node est un petit projet pratique realisé dans le cadre de mon apprentissage de JavaScript avec Node.js et Visual Studio Code.

       # Objectifs
1. comprendre les bases de JavaScript
2. Apprendre à déclarer et utiliser des variables.
3. Manipuler les entées et les sorties dans terminal

      # Technologies utilisées
1- JavaScript
2-Node.js
3-Visual Stuido Code
    
       # Fonctionnement

    ce programme utilise le module readline de Node.js pour demander à l'utilisateur de saisir un nombre dans le terminal. la réponse est ensuite convertie en nombre à l'aide de Number(), puis affichées avec console.log.

       # Exécution

1- Installer Node.js
2-Ouvrir le dossier app-node dans visual studio code
3-Ouvrir le terminal intégré
4- Exécuter la commande suivante :
node index.js
